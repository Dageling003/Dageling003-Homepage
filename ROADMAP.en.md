## Current status

This project has **no active development plan** at the moment.

The author is unable to continue due to personal reasons. Before moving forward, we need to hear from real users to decide the next direction. The roadmap is frozen until then.

Released versions (v1.0–v1.1) remain fully functional: one-command deploy, admin config management, SQLite persistence, Caddy automatic HTTPS.

## Non-goals

- Multi-user / multi-tenant: serves one person only.
- Heavyweight CMS: no category trees, threaded comments, or editorial workflows.
- Drag-and-drop visual editor: layout comes from conventions and forms.
- Mobile apps: the responsive admin is sufficient.
- Legacy browser support: only the two most recent major versions of modern browsers.
